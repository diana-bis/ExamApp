# E-Test System

A full-stack exam management application built with React. 

---

## Tech Stack

- **React 18** with Vite
- **React Router v6** (HashRouter for static hosting)
- **Bootstrap 5** (CDN)
- **In-memory mock backend** (MockDatabase singleton)

---

## Getting Started

```bash
cd client
npm install
npm run dev
```

App runs at `http://localhost:5173`
